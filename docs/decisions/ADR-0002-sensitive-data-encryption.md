# ADR-0002: 민감 데이터 암호화 방향

- 상태: 설계 원칙 승인, 세부 구현은 보안 검토 후 확정
- 날짜: 2026-11-08

## 맥락

개인정보가 SQLite/MSSQL에 평문으로 저장되는 것을 방지해야 합니다. 동시에 월별 생일 등 구조화된 검색은 유지해야 합니다.

## 결정

- 민감 필드는 애플리케이션 계층에서 AES-256-GCM 암호화하는 방향으로 설계
- 암호화 키는 DB와 분리
- Windows 개인 설치는 OS 키 보호 기능을 Provider로 캡슐화
- 백업도 암호화
- 로그에는 개인정보 원문을 기록하지 않음
- 검색용 HMAC 토큰은 위협 모델 및 테스트 후 채택 여부 확정

## 트레이드오프

- 암호화 값은 일반 SQL 문자열 검색 불가
- 검색용 메타데이터는 일부 정보 노출 가능성이 있음
- 키 분실 시 데이터 복구가 어려울 수 있음
- 실행 중 메모리/GPU의 평문까지 저장 암호화가 보호하지는 않음

## 후속 검증

- 키 생성·백업·복원·회전 테스트
- AES-GCM nonce 관리 검증
- DB 파일과 백업 파일 평문 검사
- 월별 생일 조회 성능 및 메타데이터 노출 비교
