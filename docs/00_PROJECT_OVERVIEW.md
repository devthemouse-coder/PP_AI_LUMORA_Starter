# 00. 프로젝트 개요

## 1. 제품 정의

P.P. AI - LUMORA는 사용자의 정보를 로컬 환경에 안전하게 기억하고, 자연어 질문을 통해 해당 정보를 검색·활용하며, 반복적인 업무 절차를 점진적으로 지원하는 Private Personal AI Platform입니다.

초기 프로젝트명은 임시 명칭입니다. 상표·도메인 검색 후 변경할 수 있으므로 제품 표시명과 내부 기술 식별자를 분리합니다.

## 2. 해결하려는 문제

일반적인 LLM은 대화가 끝난 뒤에도 사용자가 알려준 사실을 안정적으로 보존하거나, 사실 데이터의 정확한 조회·수정·삭제를 보장하는 개인 데이터베이스 역할을 하지 않습니다.

LUMORA는 다음을 분리합니다.

- LLM: 자연어 이해, 정보 추출, 답변 문장 생성
- Memory: 사용자가 제공한 사실과 맥락의 영속 저장
- Application: 권한 확인, 검증, 검색, 변경, 도구 실행 통제
- Database: 구조화된 원본 데이터 보관

## 3. 대표 사용 시나리오

1. 사용자가 "김철수는 7월 15일이 생일이야"라고 입력합니다.
2. 시스템은 후보 기억을 추출합니다.
3. 이름·날짜·소유 범위·출처를 검증합니다.
4. 사용자의 확인이 필요한 모호성이나 충돌이 있으면 저장 전에 질문합니다.
5. 승인된 사실을 구조화해 DB에 저장합니다.
6. 사용자가 "이번 달 생일자가 누구야?"라고 질문합니다.
7. 시스템은 현재 날짜를 기준으로 DB를 조회합니다.
8. 조회 결과만을 LLM에 전달해 한국어로 정리합니다.
9. 근거 데이터가 없으면 추측하지 않고 모른다고 답합니다.

## 4. 제품 확장 방향

- Personal: 개인 PC 단독 설치, SQLite
- Private Server: 개인 서버/NAS 또는 사내 서버, 중앙 DB
- Enterprise: 다중 사용자, 조직·테넌트 분리, MSSQL
- Commercial: 설치·라이선스·업데이트·감사 기능

초기 MVP는 개인 PC 단독 설치를 대상으로 합니다. 다중 사용자와 상용 운영 기능은 데이터 경계가 무너지지 않도록 설계에 반영하되 구현은 후속 단계로 둡니다.

## 5. 범위 제외

초기 MVP에서는 다음을 구현하지 않습니다.

- 외부 LLM API 연동
- 자동 인터넷 검색 및 외부 사이트에 사용자 데이터 전송
- 음성 비서·실시간 음성 대화
- 모바일 네이티브 앱
- 모델 가중치 자체 학습 및 파인튜닝
- 다중 에이전트 오케스트레이션
- 대규모 벡터 검색 시스템
- ERP·그룹웨어 등 외부 업무 시스템 연동

## 6. 성공 기준

- 입력한 생일 정보가 구조화되어 저장된다.
- 현재 날짜 기준의 이번 달 생일자를 정확히 조회한다.
- 기존 기억의 수정·삭제가 가능하다.
- 근거가 없는 질문에는 모른다고 답한다.
- 앱을 재시작해도 기억이 유지된다.
- 인터넷 연결을 끊어도 핵심 대화·기억 기능이 동작한다.
- 외부 LLM API 호출이 없음을 코드와 네트워크 검증으로 확인한다.
- 개인정보 암호화 및 키 분리 정책이 구현·검증된다.
