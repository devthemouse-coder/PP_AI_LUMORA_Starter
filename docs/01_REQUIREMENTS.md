## 비기능 요구사항

- NFR-001: 사용자 데이터와 프롬프트는 외부 AI 서비스로 전송하지 않는다.
- NFR-002: 기본 추론은 로컬 LLM 런타임에서 수행한다.
- NFR-003: 모델 공급자 교체가 Domain/Application 변경을 최소화하도록 한다.
- NFR-004: SQLite와 MSSQL의 데이터 접근 구현을 분리한다.
- NFR-005: 개인정보 및 민감 기억은 저장 시 암호화한다.
- NFR-006: 암호화 키는 DB 및 DB 백업과 분리한다.
- NFR-007: 모든 기억은 사용자/소유 범위 및 권한을 확인한 뒤 접근한다.
- NFR-008: 감사 로그에 비밀정보와 원문 개인정보를 남기지 않는다.
- NFR-009: 핵심 기능은 인터넷 차단 상태에서 동작해야 한다.
- NFR-010: 백업·복원 및 데이터 내보내기 절차를 제공한다.
- NFR-011: API 계약과 DB 스키마를 문서화한다.
- NFR-012: 모든 성능 최적화는 측정 결과에 근거한다.

## 보안·정확성 관련 수용 기준

- 존재하지 않는 생일을 모델이 만들어내지 않는다.
- 저장된 생일과 조회 결과가 일치한다.
- 충돌하는 정보는 자동 덮어쓰기하지 않고 확인한다.
- 날짜·시간 기준은 시스템이 제공한 현재 시각과 시간대를 사용한다.
- 사용자 입력을 SQL로 직접 실행하지 않는다.
- LLM이 제안한 도구 호출은 서버의 권한 검사와 입력 검증을 거친다.
- 삭제는 정책에 따라 실제 삭제 또는 명시적 비활성화로 처리하고 결과를 사용자에게 알린다.
