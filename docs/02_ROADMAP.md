# 02. 개발 로드맵

일정은 1인 개발 기준의 계획이며, 각 단계의 검증 결과에 따라 조정합니다. 날짜를 확정한 약속이 아닙니다.

## Phase 0 — 개발 기반

- 개발 도구 버전 확인
- VS Code 확장 설치 및 동작 확인
- Git 저장소 초기화
- 솔루션·폴더 구조 결정
- Ollama 상태와 GPU 인식 확인
- 모델 후보의 메모리 요구량·라이선스 확인

완료 조건: 빈 프로젝트가 로컬에서 빌드되고, 도구 버전과 실행 결과가 기록됨.

## Phase 1 — Backend/Frontend 골격

- ASP.NET Core API
- Vue 3 + TypeScript + Vite
- API 계약(OpenAPI)
- 헬스 체크
- 기본 화면과 오류 표시

완료 조건: 브라우저에서 화면을 열고 백엔드 헬스 체크 결과를 확인함.

## Phase 2 — LLM 연결

- LLM 추상화 인터페이스
- Ollama Provider
- 모델 설정 및 연결 상태
- 일반 응답과 스트리밍
- 시간 초과·취소·연결 실패 처리

완료 조건: 로컬 모델에 질문하고 답변을 받으며, 외부 LLM 호출이 없음을 확인함.

## Phase 3 — 기억 저장

- 기억 도메인 모델
- SQLite Repository
- 기억 추출 결과 구조화
- 확인·충돌 처리
- 암호화 저장
- 수정·삭제

완료 조건: 합성 생일 데이터 저장·조회·수정·삭제 테스트 통과.

## Phase 4 — 기억 검색과 답변

- 자연어 질의 의도 분석
- 허용된 조회 기능 선택
- 서버에서 DB 조회
- 조회 결과 기반 답변
- 출처와 불확실성 표현

완료 조건: 이번 달 생일자 조회와 근거 없는 질문의 거절/모름 응답 검증.

## Phase 5 — 안정화

- 백업·복원
- 오프라인 동작 검증
- 네트워크 송신 검증
- 성능 측정
- 보안 테스트
- 설치·초기 설정 문서

## 후속 단계

- MSSQL Provider
- 다중 사용자 및 조직 격리
- 문서 RAG
- 절차 기억
- 로컬 음성·파일 처리
- 제품 라이선스 및 업데이트 체계
